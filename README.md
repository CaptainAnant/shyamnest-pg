## 🎯 About

ShyamNest PG is a web application designed to help students find suitable room accommodations and PG facilities. The platform connects students with property owners, making it easier to search, compare, and book rooms online.

## ✨ Features

- **Room Search & Listing** - Browse and search for available PG rooms and accommodations
- **Detailed Room Information** - View comprehensive details, amenities, and photos
- **User Profiles** - Create accounts for both students and property owners
- **Booking Management** - Easy booking and cancellation system
- **Filter & Sort** - Advanced filtering by price, location, amenities, and more
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Contact Management** - Direct communication with property owners

## 🛠 Tech Stack

- **Frontend:** JavaScript (64.2%), HTML (18.2%), CSS (17.6%)
- **Architecture:** Single Page Application (SPA)
- **Styling:** CSS with responsive design principles
- **Interactivity:** Vanilla JavaScript

## 📦 Installation

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Git

### Steps

1. Clone the repository:
```bash
git clone https://github.com/CaptainAnant/shyamnest-pg.git
cd shyamnest-pg
```

2. Open the project:
```bash
# Simply open index.html in your browser
# Or use a local development server
python -m http.server 8000
# Then visit http://localhost:8000
```

## 🚀 Usage

1. **Navigate to the website** - Open the application in your web browser
2. **Search for accommodations** - Use the search bar to find rooms by location, price, or amenities
3. **View details** - Click on listings to see full details and photos
4. **Book a room** - Follow the booking process to reserve your accommodation
5. **Manage bookings** - Access your dashboard to view and manage your reservations
